# Coffee Shop Backend API

A RESTful API build with Laravel for managing coffee shop operations, orders, and sales analytics.

## Setup & Installation

1. Clone the repository
2. Run `composer install`
3. Copy `.env.example` to `.env` and set up database credentials
4. Run `php artisan migrate --seed`
5. Run `php artisan serve`

## API Documentation

For the full list of API endpoints, request bodies, and sample responses, please refer to [API_DOCUMENTATION.md]
